# Evolved Tech 🚀

**From Lagos to the world.** 

Welcome to the official repository for Evolved Tech. We are a technology studio dedicated to building browser-first tools, platforms, and interactive experiences. 

While we are best known for creating **Limn Engine** (our zero-config 2D game engine), this repository houses our entire ecosystem of upcoming projects, including developer tools, educational platforms, and social networks.
